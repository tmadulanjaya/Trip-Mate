\# TripMate



TripMate is a collaborative travel-planning application.



\## Planned features



\- Create and manage trips

\- Build day-by-day itineraries

\- Manage packing lists

\- Track group expenses

\- Vote on activities and restaurants

\- Add comments

\- Synchronize updates in real time



\## Planned technology



\- React

\- Node.js

\- Express

\- MongoDB

\- Mongoose

\- JWT authentication

\- Socket.io

\- Docker

\- GitHub Actions
